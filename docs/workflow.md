# MOP Workflow Engine

MOP Flow uses a 10-phase BMAD-inspired workflow.

## Phases
1. `idea` -> Idea Capture
2. `brief` -> Product Brief
3. `prd` -> PRD
4. `ux-spec` -> UX Spec
5. `architecture` -> Architecture
6. `story` -> Implementation Story
7. `readiness` -> Readiness Gate
8. `implementation` -> Implementation
9. `review` -> Review
10. `release` -> Release
